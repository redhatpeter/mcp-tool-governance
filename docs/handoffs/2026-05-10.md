## What changed in code

### `apps/dup-resolver/check_pr.py`

- **Rename detection:** new `diff_deleted_operations(base_ref, file_path)`
  computes `base_ops − head_ops` per spec file. `score_candidate()`
  receives a `deleted_in_pr: dict[str, set[str]]` map; if the top hit's
  `(server, tool_name)` is in that set, the verdict is downgraded
  `DUPLICATE → INFO` with reason *"is being deleted in this PR — looks
  like a rename, not a duplicate"*. The required check still passes
  (exit 0) so renames don't block merges.
- **Index freshness signal:** vector-query `select` includes
  `last_seen_utc`; `render_report()` emits a footer with the oldest
  top-hit timestamp so reviewers can see the index age.
- New verdict emoji `INFO → ℹ️` and a rename count in the summary line.
